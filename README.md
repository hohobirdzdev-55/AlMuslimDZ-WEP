# الموقع الرسمي لتطبيق AlMuslimDZ – المسلم DZ

الموقع التعريفي الرسمي لتطبيق Android الإسلامي **AlMuslimDZ – المسلم DZ** مع رابط مباشر لتحميل ملف APK.
تم بناء الموقع باستخدام **React + Vite + Tailwind CSS** بدعم كامل للغة العربية (RTL) وتصميم عصري وإسلامي راقٍ.

---

## 1. كيفية تشغيل المشروع محلياً (Local Development)

لتشغيل المشروع على جهازك:

```bash
# تثبيت التبعيات
npm install

# تشغيل خادم التطوير
npm run dev
```

سيفتح الموقع على الرابط: `http://localhost:3000`

---

## 2. أين تضع شعار التطبيق (Logo)

ملف الشعار موجود في المسار:

```text
public/logo.png
```

* **طريقة التحديث:** كل ما عليك فعله هو وضع ملف الشعار الخاص بك بصيغة PNG وتسميته `logo.png` واستبدال الملف الموجود في مجلد `public/`.
* سيظهر الشعار الجديد تلقائياً في شريط التنقل، وقسم Hero، وخاتمة الموقع دون الحاجة إلى تعديل أي سطر برمجي.

---

## 3. أين تضع لقطات الشاشة الحقيقية (Screenshots)

جميع لقطات الشاشة توضع داخل المجلد:

```text
public/screenshots/
```

* يمكنك في أي وقت حذف الصور المؤقتة ووضع لقطات الشاشة الحقيقية من هاتفك **بنفس أسماء الملفات**، وستظهر مباشرة في كل أقسام الموقع وفي المعرض والموك أب (Mockups).

## 5. أين تضع ملف APK (تحديث التطبيق)

ملف الـ APK المخصص للتحميل المباشر موجود في المسار:

```text
public/downloads/AlMuslimDZ.apk
```

* **لتحديث نسخة التطبيق:** انسخ ملف الـ APK الجديد الخاص بك وقم بتسميته `AlMuslimDZ.apk` ثم ضعه داخل مجلد `public/downloads/` مستبدلاً الملف القديم.
* جميع أزرار "تحميل التطبيق مجاناً" في الموقع مرتبطة تلقائياً بالمسار `/downloads/AlMuslimDZ.apk`، مما يعني أن المستخدمين سيحمّلون نسختك الأحدث فوراً دون أي تعديل في الكود.

---

## 6. كيفية تغيير رابط سياسة الخصوصية (Privacy Policy)

تم وضع رابط سياسة الخصوصية في مكان واحد ومركزي داخل ملف:

```text
src/config.ts
```

في السطر رقم 8 ستجد المتغير:

```typescript
export const PRIVACY_POLICY_URL = '/privacy-policy.html';
```

عندما تجهز رابط سياسة الخصوصية الخارجي (مثلاً على Vercel أو Google Docs)، قم فقط بتغيير القيمة:

```typescript
export const PRIVACY_POLICY_URL = 'https://your-privacy-policy-link.vercel.app';
```

وسينعكس الرابط فوراً في كل أنحاء الموقع.

## 7. كيفية بناء المشروع (Production Build)

لبناء الموقع للإنتاج:

```bash
npm run build
```

سيتم إنشاء ملفات الويب الجاهزة داخل مجلد `dist/`.

---

## 8. كيفية نشر المشروع على Vercel

المشروع متوافق ومجهز بالكامل للنشر الفوري على منصة **Vercel**:

### الطريقة الأولى: عبر لوحة تحكم Vercel (موصى بها)
1. ارفع المشروع إلى حسابك على **GitHub**.
2. ادخل إلى [vercel.com](https://vercel.com) وسجّل الدخول.
3. اضغط على **Add New Project** واختر مستودع (Repository) الخاص بك.
4. سيتعرف Vercel تلقائياً على إعدادات **Vite**:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. اضغط **Deploy**، وسيتم نشر الموقع خلال ثوانٍ مع شهادة SSL مجانية.

### الطريقة الثانية: عبر Vercel CLI
```bash
npm install -g vercel
vercel
```
